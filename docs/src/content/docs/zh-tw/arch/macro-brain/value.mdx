[價值網路](/zh-tw/arch/macro-brain/network/)最後輸出每層一個數。本節把這些數變成做決定用的價值，然後反過來：一個記錄下來的決策如何成為訓練樣本、損失，以及網路怎麼訓練。

## 1. V 是什麼

**V(s) = P(從 s 起贏下這一局，由目前的冠軍來打)**。一個局面的 V，就是由*冠軍*（目前接受的最好的 AI 版本）打完剩下的部分時，這一局從那裡贏下的機率。

- **同一個尺度**：每個價值都是同一件事的機率，所以休息處的回血、獎勵裡的一張牌和地圖上的一條路都能直接比較，不需要手寫的換算率（[後狀態 §2](/zh-tw/arch/macro-brain/afterstates/#sec-2)）。
- **只看觀測**：V 讀整局觀測，也就是玩家在戰鬥外看到的東西（[Harness：決策日誌 §7](/zh-tw/arch/harness/decision-log/#sec-7)）。
- **兩種環境一個 V**：SL 策略之後的每個節點都打得比 NoSL 策略好，所以從同樣的觀測出發，它真正贏下的機率更高；共用的 V 刻意忽略這一點（[環境：世界與兩種戰鬥演算法 §6](/zh-tw/arch/environments/worlds/#sec-6)）。V 用 SL 對局訓練，那些對局的戰鬥由 SL 規劃器來打。
- **在某個策略之下**：「由目前的冠軍來打」很重要：同一個局面在更強的玩家手上更值錢。這就是網路只用最新一代的對局訓練的原因（[自我對弈 §4](/zh-tw/arch/macro-brain/selfplay/#sec-4)）。

## 2. 從風險值到價值

V 不直接預測獲勝的機率。它的輸出頭對從 0 到 63 的每一層 $g$ 預測一個**風險值**（hazard）

$$
h_g = P(\text{the run ends on floor } g \mid \text{it is still going on floor } g),
$$

這是統計學裡的離散時間存活模型（*風險*是在某個時間點發生事件的機率，前提是事件在那之前還沒發生），只是這裡由一個神經網路從這一局算出每一層的風險值（如 Gensheimer 與 Narasimhan，2019）。其他一切都靠連乘得到。從這一局目前的樓層 $f$ 起：

$$
S_g = \prod_{j=f}^{g} (1 - h_j), \qquad e_g = S_{g-1}\, h_g \quad (S_{f-1} = 1).
$$

$S_g$ 是過了第 $g$ 層還在繼續的機率，$e_g$ 是這一局恰好在第 $g$ 層結束的機率。於是：

- **P(win)** 是撐過每一層的機率：$S_{63}$。贏下的對局被標成撐過全部各層（[§3](#sec-3)），所以這就是這一局贏下的機率。這就是 V 的價值：網路檔案的 `objective` 是 `win`，由 `RunNet.Value` 計算這個連乘。
- **期望到達樓層**來自同樣的風險值：$\mathbb{E}[F] = f + \sum_{g \ge f} S_g$。訓練報告會用它（[§6](#sec-6)）；沒有任何決定靠它。

為什麼用風險值，而不是一個輸出直接給獲勝的機率：

- **每一層都有標籤**：贏下的對局很少：一代的自我對弈 21,275 局裡只有 286 局（[自我對弈 §4](/zh-tw/arch/macro-brain/selfplay/#sec-4)）。如果是單一目標，幾乎每個樣本都只會說「輸了」。一個撐過第 5 到 32 層、死在第 33 層的樣本，對其中每一層都有話說。
- **停下的對局也算數**：被提前中止的對局（*設限*，censored：被截斷，或限時結束）對它停下之後的樓層什麼也沒說，遮罩直接把它們略過。單一目標就只能用猜的。
- **整個分布**：同一個輸出頭給出這一局可能在哪裡結束，報告可以讀它。

為什麼用獲勝的機率，而不是到達的樓層：樓層把每一層看得一樣重，所以可能偏向穩定打到第 2 幕的穩妥路線，而不是偶爾能贏的冒險路線。獲勝才是目標，而對局贏得夠多，已經足以量測它。

## 3. 從記錄下來的決策到樣本

`learn/v/data.py` 建出樣本。自我對弈日誌裡的每個宏觀決策都是一個樣本：那個決策處的整局觀測（[Harness：決策日誌 §7](/zh-tw/arch/harness/decision-log/#sec-7)），按對局 id 連接到這一局的記錄，記錄說明這一局在哪裡結束（[評估：指標、種子與報告 §8](/zh-tw/arch/evaluation/metrics/#sec-8)）。失敗對局的決策不算在內。一次選路還給出第二個樣本，也就是選中的點的後狀態，因為 V 給地圖選項估值時讀的正是它，而記錄的整局觀測裡都沒有它（[價值網路 §4](/zh-tw/arch/macro-brain/network/#sec-4)）。它的目標是這一局的真實結果，即**蒙地卡羅（MC）目標**：沒有估計，沒有自舉，只有實際發生的事。

一個樣本包含：

- 它的**詞元和數字**，從觀測讀出（[價值網路 §2](/zh-tw/arch/macro-brain/network/#sec-2)）。觀測本身被丟棄：做成 Python 物件時，一個觀測大約大十倍。留出的樣本把觀測存成 JSON，供網路檔案的測試對局使用。
- 它的**起點** $s$，即觀測的樓層，以及它那一局的**終點** $e$，即到達的樓層，兩者最多都是 63；
- 它那一局的**結局類型**：死亡、贏下或設限；
- **接下來幾場戰鬥的生命值花費**，給第二個輸出頭用（[§4](#sec-4)）；
- 它的**權重**（[見下](#sec-3)）。

**標籤：只用測量到的**。對一個在第 $s$ 層取得、所屬對局結束在第 $e$ 層的樣本，每一層 $g$ 得到一個標籤 $y_g$，或者沒有標籤：

| 這一局 | $g < s$ | $s \le g < e$ | $g = e$ | $g > e$ |
|---|---|---|---|---|
| 死在第 $e$ 層 | 無 | 0（撐過） | 1（結束） | 無 |
| 贏下 | 無 | 0 | 0 | 0 |
| 在第 $e$ 層設限 | 無 | 0 | 無 | 無 |

例如，一個在第 5 層做的決策，所屬對局死在第 33 層，有 29 個標籤：第 5 到 32 層是 0，第 33 層是 1。一個在第 5 層做的決策，所屬對局贏下，有 59 個標籤：第 5 到 63 層都是 0。

一個樣本的**損失**是它有標籤的各層上風險值的二元交叉熵，再加上第二個輸出頭的損失：

$$
\mathcal{L} = -\sum_{g \,\text{labelled}} \Big[ y_g \log h_g + (1 - y_g) \log(1 - h_g) \Big] \;+\; 3 \sum_{k} \big( \hat c_k - c_k \big)^2 ,
$$

其中 $c_k$ 是接下來第 $k$ 場戰鬥花掉的最大生命值比例，$\hat c_k$ 是第二個輸出頭對它的預測。

**每一局權重相同**。一局的所有決策共用一個結果，而一局有遠超過一百個決策。每個樣本的權重是它那一局決策數的倒數，所以一局長的對局只算一次，而不是 180 次，一個批次的損失則是加權平均。AlphaGo 的價值網路每盤棋只用一個局面訓練（Silver 等人，2016），也是出於同樣的顧慮：同一盤棋的局面高度相關，用全部局面訓練的網路會記住棋局。

**按對局留出**。每五局取一局，按它的對局 id（`int(run_id, 16) % 5 == 0`），連同它所有的決策留出，用於提前停止和報告。如果按決策劃分，同一局的決策會出現在兩邊，誇大網路的表現。

<Aside>

**MC 在這裡的意思**。標籤是這一局在打它的那個策略下怎麼結束的，包括決策之後的一切：戰鬥規劃器的運氣，以及自我對弈裡之後的探索抽取（[自我對弈 §3](/zh-tw/arch/macro-brain/selfplay/#sec-3)）。這讓它對那個策略是無偏的，對任何單一決策則雜訊很大。

</Aside>

## 4. 第二個輸出頭

第二個輸出頭只在訓練時使用，用六個 sigmoid 輸出預測這一局接下來六場戰鬥各花掉最大生命值的多少比例。死亡算花掉剩下的全部；前方不到六場戰鬥的對局，只有那幾場有目標。它的平方誤差以權重 3 加入損失。它的第七個輸出是給模擬頭目戰當額外標籤用的，整局訓練不用這些標籤，所以那裡沒有目標。

它從不用來做決定，也不在網路檔案裡。它的作用是塑造主幹：一場戰鬥的生命值花費在每一局裡會測到好幾次，所以它給主幹的目標遠多於那一個結果，而且全都關於 V 必須判斷的同一件事：這一局面對接下來的戰鬥有多強。

## 5. 訓練

```text
uv run python -m v.train --list PREFIX --name NAME --objective win [--init FILE]
```

`learn/v/train.py`。大小和設定寫死在程式碼裡，不是選項；實驗就在那裡改，只有有結果才保留改動：

| 設定 | 值 |
|---|---|
| 樓層 | 64，從第 0 層起 |
| 最佳化器 | AdamW，學習率 $3 \times 10^{-5}$，權重衰減 $10^{-4}$ |
| 批次 | 256 個樣本，每輪重新打亂 |
| 輪數 | 最多 40 輪，連續 5 輪留出的風險值損失沒有降低 $10^{-4}$ 就停；保留最佳一輪的權重 |
| 詞元表 | 遊戲的，固定不變（[價值網路 §2](/zh-tw/arch/macro-brain/network/#sec-2)） |
| 第二個輸出頭 | 權重 3 |
| 起點 | 風險值輸出頭的偏置設在基線（[見下](#sec-5)） |

**為什麼學習率這麼小，又從基線出發**。資料的規模雖大，結果卻少，網路過擬合得很快：它能在一輪之內記住一個狀態來自哪一局。所以風險值輸出頭的偏置從每一層在訓練對局上的風險值開始，

$$
\frac{\text{deaths}_g + 0.5}{\text{alive}_g + 1},
$$

兩者都按樣本的權重計數，網路只需要學這一局如何讓每一層的風險值偏離平均值。它移動得夠慢，留出的對局才能說出什麼時候該停。

**從一個網路接著訓練**（`--init`）。訓練可以從一個先前的網路檔案開始，而不是從零開始：它的標準化參數和它的權重，權重從它的 ONNX 計算圖讀回（`export.weights`）。第二個輸出頭不在檔案裡，重新開始。這種結構的網路只能從同樣結構的網路接著訓練，表和遊戲的不同的檔案會被拒絕。

**在 GPU 上**，一個批次的張量先從樣本建成清單，再各成一個張量。每次訓練在一張 GPU 上跑。

## 6. 報告

訓練器印出一份報告，並寫進網路檔案（`fit`）。全部都在留出的對局上量測：

| 欄位 | 內容 |
|---|---|
| `runs`、`held_out_runs`、`samples`、`won` | 訓練讀了什麼 |
| `vocab` | 每張詞元表的大小 |
| `held_out_loss`、`held_out_loss_floor_only` | 風險值的損失，對比只知道樓層的基線的損失 |
| `held_out_next_combats` | 第二個輸出頭的誤差 |
| `r2_held_out`、`r2_held_out_floor_only` | 期望樓層對到達樓層的 $R^2$，以及基線的 $R^2$ |
| `brier_held_out`、`brier_held_out_floor_only` | P(win) 的 Brier 分數：（預測的機率 − 是否贏下）² 的加權平均，以及基線的分數 |
| `won_held_out_runs` | 留出的對局裡贏下幾局 |

$R^2$ 和 Brier 分數衡量 V 區分不同對局的狀態有多好。一個決策只需要 V 把同一個狀態的各選項排對順序，兩者都量不到這一點。這就是為什麼每個網路都靠實際對打來評判（[自我對弈 §5](/zh-tw/arch/macro-brain/selfplay/#sec-5)）。
