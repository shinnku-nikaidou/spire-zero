[價值網路](/zh-tw/arch/macro-brain/network/)最後輸出每層一個數。本節把這些數變成做決定用的價值，然後反過來：每個訓練樣本的目標是什麼、損失，以及網路怎麼訓練。

## 1. 從風險值到價值

V 不直接預測價值。它的輸出頭對從 0 到 63 的每一層 $g$ 預測一個**風險值**（hazard）

$$
h_g = P(\text{the run ends on floor } g \mid \text{it is still going on floor } g),
$$

這是統計學裡的離散時間存活模型（*風險*是在某個時間點發生事件的機率，前提是事件在那之前還沒發生），只是這裡由一個神經網路從這一局算出每一層的風險值（如 Gensheimer 與 Narasimhan，2019）。其他一切都靠連乘得到。從這一局目前的樓層 $f$ 起：

$$
S_g = \prod_{j=f}^{g} (1 - h_j), \qquad e_g = S_{g-1}\, h_g \quad (S_{f-1} = 1),
$$

$S_g$ 是過了第 $g$ 層還在繼續的機率，$e_g$ 是這一局恰好在第 $g$ 層結束的機率。於是：

- **期望到達樓層**：到達的樓層是 $f$ 加上從 $f$ 起撐過的層數，所以 $\mathbb{E}[F] = f + \sum_{g \ge f} S_g$。
- **P(win)**：當贏下的對局被標成撐過每一層時（整局，[§2](#sec-2)），獲勝的機率就是全部撐過的機率：$S_{63}$。
- **進度**（菁英連戰的 V）：另一個輸出頭（比例頭）對每一層給出一個**比例** $s_g$：這一局若在那裡結束，結束它的那場戰鬥裡打掉的敵人生命比例。期望進度把它加到期望樓層上：

$$
\mathbb{E}[\text{progress}] = \mathbb{E}[F] + \sum_{g \ge f} e_g\, s_g .
$$

`RunNet.Value` 正是這樣計算，網路檔案的 `objective`（`floor`、`win` 或 `progress`）說明三者中哪一個是 V 的價值。v6-3-2 的是 `progress`。

圖中是 v6-3-2 對一個局面的輸出頭。風險值在大多數樓層都很低，在第 2、3 幕的頭目處（第 33 和 48 層）陡然升高：連戰的對局就結束在那裡。第 1 幕頭目（第 17 層）只是一個小台階，到達它的對局裡 v6-3-2 有 96% 打贏。存活曲線在每個尖峰處往下一階，第三張圖是這一局在哪裡結束的分布；它的平均值加上那些比例，就是進度。降低生命值，尖峰就會變高。

為什麼用風險值，而不是一個數：

- **每一層都有標籤**：一個撐過第 5 到 32 層、死在第 33 層的樣本，對其中每一層都有話說，而不只是「33」。這是比單一回歸目標更密集的訊號。
- **停下的對局也算數**：被提前中止的對局（*設限*，censored：被截斷，或限時結束）對它停下之後的樓層什麼也沒說，遮罩直接把它們略過（[§2](#sec-2)）。單一的「到達樓層」目標就只能用猜的。
- **一個輸出頭，多種價值**：同樣的風險值給出期望樓層、P(win)，以及這一局在哪裡結束的整個分布，所以目標可以改變，而不用改網路（[§6](#sec-6)）。

<Aside>

**v6-3-2 沒有 P(win)**。菁英連戰把*贏下*的對局標成結束在最後一層，比例為 1（最後的頭目全部打掉），所以它的進度是最後一層 + 1。因此第 48 層的風險值是「這一局結束在最後的頭目處，不論輸贏」，而 $S_{63}$ 對每個狀態都接近 0。用「贏下的對局撐過每一層」來訓練的整局 V，從同一個輸出頭讀出 P(win)；那是下一個計畫的目標（[弱點與下一步 §2](/zh-tw/arch/macro-brain/next/#sec-2)）。

</Aside>

## 2. 標籤：只用測量到的

自我對弈日誌裡的每個宏觀決策都是一個訓練樣本：那個決策處的整局觀測（[Harness：決策日誌 §7](/zh-tw/arch/harness/decision-log/#sec-7)），按對局 id 連接到這一局的記錄，記錄說明這一局在哪裡結束（[評估 §6](/zh-tw/arch/evaluation/#sec-6)）。它的目標是這一局的真實結果，即**蒙地卡羅（MC）目標**：沒有估計，沒有自舉，只有實際發生的事。

對一個在第 $s$ 層取得、所屬對局結束在第 $e$ 層的樣本，每一層 $g$ 得到一個標籤 $y_g$，或者沒有標籤：

| 這一局 | $s \le g < e$ | $g = e$ | $g > e$ |
|---|---|---|---|
| 死在第 $e$ 層 | 0（撐過） | 1（結束） | 無 |
| 贏下（整局） | 0 | 0 | 0 |
| 在第 $e$ 層設限 | 0 | 無 | 無 |

在菁英連戰裡，結束了的對局，不論輸贏，都標成結束在它最後所在的那一層，比例頭學那一層的比例：贏下的對局是 1，死在戰鬥裡的對局是打掉的敵人生命比例，死在戰鬥之外的是 0。一個樣本的損失是它有標籤的各層上風險值的二元交叉熵，在連戰裡再加上它結束那一層的比例的交叉熵：

$$
\mathcal{L} = -\sum_{g \,\text{labelled}} \Big[ y_g \log h_g + (1 - y_g) \log(1 - h_g) \Big] \;-\; \Big[ \sigma_e \log s_e + (1 - \sigma_e) \log(1 - s_e) \Big],
$$

其中 $\sigma_e$ 是實際打掉的比例。下圖用 v6-3-2 自己的風險值，為一個局面計算第一項：選這一局怎麼結束、在哪裡結束，看看哪些樓層有標籤，每一層給損失加了多少。

<LabelMask client:visible lang="zh-TW" start="test-4" />

**每一局權重相同**。一局的所有決策共用一個結果。一局菁英連戰在第 1 代平均有 108 個宏觀決策，第 3 代 146 個，所以第 3 代的 2,160,792 個決策只有 14,828 個結果。每個樣本的權重是它那一局決策數的倒數，所以一局長的對局只算一次，而不是 180 次。AlphaGo 的價值網路每盤棋只用一個局面訓練（Silver 等人，2016），也是出於同樣的顧慮：同一盤棋的局面高度相關，用全部局面訓練的網路會記住棋局。

**按對局留出**。每五局取一局（按對局 id），連同它所有的決策留出，用於提前停止和報告。如果按決策劃分，同一局的決策會出現在兩邊，誇大網路的表現。

**MC 在這裡的意思**。標籤是這一局在打它的那個策略下怎麼結束的，包括決策之後的一切：戰鬥規劃器的運氣，以及自我對弈裡之後的探索抽取（[自我對弈 §2](/zh-tw/arch/macro-brain/selfplay/#sec-2)）。這讓它對那個策略是無偏的，對任何單一決策則雜訊很大。

## 3. 第二個輸出頭

第二個輸出頭只在訓練時使用，預測這一局接下來六場戰鬥各花掉最大生命值的多少比例（死亡算花掉剩下的全部；在連戰裡只算真打的戰鬥，即菁英和頭目）。它的平方誤差以權重 3 加入損失。它從不用來做決定，也不在網路檔案裡。它的作用是塑造主幹：一場戰鬥的生命值花費在每一局裡會測到好幾次，所以它給主幹的目標遠多於那一個結果，而且全都關於 V 必須判斷的同一件事：這一局面對接下來的戰鬥有多強。在 V v2 的資料上，用三個訓練種子，它在每個種子上都降低了留出損失（平均 1.222 對 1.235），也提高了 $R^2$（0.384 對 0.371）。

## 4. 訓練

`uv run python -m v.train`（`learn/v/train.py`）。大小和設定寫死在程式碼裡，不是選項；實驗就在那裡改，只有有結果才保留改動：

| 設定 | 值 |
|---|---|
| 嵌入、單牌網路、主幹 | 32、128、256 |
| 最佳化器 | AdamW，學習率 $3 \times 10^{-5}$，權重衰減 $10^{-4}$ |
| 批次 | 256 個樣本 |
| 輪數 | 最多 40 輪，連續 5 輪留出損失沒有改善就停 |
| 未知 id | 出現不到 3 次的 id |
| 第二個輸出頭 | 權重 3 |
| 起點 | 風險值輸出頭的偏置設在基線：每一層在訓練對局上的風險值，$(\text{deaths} + 0.5) / (\text{alive} + 1)$；比例頭的偏置設在平均比例 |

**為什麼學習率這麼小，又從基線出發**。資料的規模雖大，結果卻少，網路過擬合得很快。在 V v2 的第一批資料（859 局）上，一個輸出頭隨機初始化、學習率 $10^{-3}$ 的網路一輪之內就記住了這些對局：第一輪後留出損失 1.331，第六輪後 4.12。從基線出發，同一個網路在 $10^{-3}$ 下達到 1.573，$10^{-4}$ 下 1.235，$3 \times 10^{-5}$ 下 1.229。從基線出發，網路只需要學這一局如何讓每一層的風險值偏離平均值。

**從一個網路接著訓練**（`--init`）。訓練可以從一個先前的網路檔案開始，而不是從零開始：它的詞元表（它沒見過的 id 讀作未知）、它的標準化參數和它的權重，權重從它的 ONNX 計算圖讀回。第二個輸出頭不在檔案裡，重新開始。

**記憶體**。一個樣本保留它的詞元和數字，不保留它的整局觀測：做成 Python 物件時，一個觀測大約大十倍，第 3 代的 2,160,792 個決策在保留每個觀測的訓練裡約佔 117 GB，不保留時 20.9 GB。留出的樣本把觀測存成 JSON，供網路檔案的測試對局使用。

**報告**。訓練器報告留出損失和基線的對比，以及在留出對局上，V 的價值對實際到達的進度（或樓層）的 $R^2$。第 3 代：

| 網路 | 起點 | 留出損失 | $R^2$ | 最佳輪 |
|---|---|---|---|---|
| 基線（每一層的平均風險值） | – | 1.9558 | 0.205 | – |
| v6-3-1 | 從零 | 1.7926 | 0.355 | 9 輪中的第 3 輪 |
| v6-3-2 | v6-2 的權重 | 1.7736 | 0.369 | 7 輪中的第 1 輪 |

$R^2$ 衡量 V 區分不同對局的狀態有多好。一個決策只需要 V 把同一個狀態的各選項排對順序，$R^2$ 量不到這一點；這就是為什麼每個網路都靠實際對打來評判（[自我對弈 §4](/zh-tw/arch/macro-brain/selfplay/#sec-4)）。

## 5. 有用和沒用的標籤

在菁英連戰之前，純 V 最初的幾個網路（在 1,617 局整局上）試過把模擬的頭目戰當作額外標籤。每個都用 `promotion-1` 上的 200 局 SL 評判：

| 網路 | 額外標籤 | 樓層 | 配對差 |
|---|---|---|---|
| pure-1 | 無 | 22.64 | 對隨機宏觀決策 +7.35 ± 0.62 |
| pure-1-b | 每個卡牌獎勵選項的牌組去打本幕頭目（頭目模擬） | 21.44 | 對 pure-1 −1.21 ± 0.67 |
| pure-1-d | 每一局在頭目門口的配裝，以進門時的生命值和三種最大生命比例去打（門口狀態） | 24.77 | 對 pure-1 +2.12 ± 0.70 |
| pure-1-g | 也加上頭目連戰試驗的門口狀態（第 1–3 幕） | 25.69 | 對 pure-1-d +0.93 ± 0.58 |

實測的頭目戰，在描述這一局在門口的真實配裝時有幫助，當作單一選牌的標籤時則有害（模擬戰鬥的勝算和實際打法差得很遠）。這個教訓引出了菁英連戰，在那裡每一局都直接打頭目和菁英（[自我對弈 §1](/zh-tw/arch/macro-brain/selfplay/#sec-1)）。這些標籤的細節見[學習 §2](/zh-tw/arch/learning/#sec-2)。

## 6. 由哪個目標做決定

V 的價值換過兩次，每次都是因為前一個已經不再提供資訊：

1. **期望樓層**（`floor`）。沒有對局能贏時，P(win) 處處為 0，沒有訊號；到達的樓層有。但它把每一層看得一樣重，可能偏向穩定打到第 2 幕的穩妥路線，而不是偶爾能贏的冒險路線。它只是過渡。
2. **期望進度**（`progress`，菁英連戰）。大多數連戰對局結束在頭目處，所以單靠樓層分不出打掉頭目 60% 生命的一局和只打掉 10% 的一局；比例可以。
3. **P(win)**（`win`），一旦對局偶爾能贏。用 v6-3-2 打整局 SL，300 局贏 23 局，所以條件成立，下一個計畫會訓練一個按 P(win) 做決定的整局 V（[弱點與下一步 §2](/zh-tw/arch/macro-brain/next/#sec-2)）。
