有了 $K$ 个世界（[概览 §2](/arch/pimc/#sec-2)），PIMC 把每个世界当作没有隐藏信息的游戏搜索到回合结束，再取平均（[§1](#sec-1)–[§2](#sec-2)）。这个平均是一个估计，带有噪声（[§3](#sec-3)）和两种偏差：策略融合（[§4](#sec-4)）和采样器的偏差（[§5](#sec-5)）。

## 1. 一个世界里的搜索

在每个世界里，对本回合的动作序列做深度优先搜索（`PimcBrain.SearchWorld`）：

- **每一步都可以结束回合**，并且最先尝试；然后按手牌顺序出牌，最后是药水。
- **一条路线结束**于回合结束或战斗结束之处。结束回合时，敌方回合用这个世界采样出的招真实地打完，叶子给下一个玩家回合开始时的状态估值（[叶子](/arch/combat-brain/leaf/)），所以估值看到的是敌人行动之后的状态。
- **置换**。状态按观测的哈希加上这个世界的隐藏状态合并（`ICombatWorld.HiddenKey`：抽牌堆的顺序、每条随机数流的位置、每个怪物排好的招），所以每个置换只展开一次，而看起来一样、实际抽到或掷出不同结果的两种顺序不会被合并。本回合出牌的先后顺序不进键，所以同样的牌换个顺序打，仍然会合并到一起。如果只按观测作键，这样的两个状态里先被搜到的那个会把自己的值给另一个。这种情况有多常见，用一个同时记两种键的探针量过（2026-10-27）：在静默猎手的初始牌组上（约 990 个决策，376,000 个状态），以及在一副随机效果牌组上（250 个决策，81,000 个状态，8,600 次重复），重复出现的观测没有一次带着不同的隐藏状态，所以没有决策因此改变。在 NoSL 世界里，隐藏状态是这个世界自己的样本，由观测和搜索种子抽出，所以这个键不含真实游戏的任何东西。
- **预算**。每个世界的节点（300 个）平均分给各个第一动作，让每个都得到公平的考察。在一棵子树里，一旦它的份额用完，搜索就不再展开，那里的状态按「结束回合」打分，而结束回合正是最先尝试的选项。被截断的状态不留给它的置换复用，因为它的值只是一个下界。

这个世界给出的答案是：对每个第一动作 $a$，$a$ 之后的最好路线及其估值。

## 2. 按第一动作取平均

对一个第一动作 $a$，PIMC 计算

$$
\hat Q(a) = \frac{1}{K} \sum_{k=1}^{K} \max_{\pi} V\big(\mathrm{leaf}(s_k, a, \pi)\big), \qquad s_k \sim \tilde P(s \mid h),
$$

其中 $\pi$ 取遍本回合剩下的打法，$\mathrm{leaf}(s_k, a, \pi)$ 是世界 $k$ 里下一个回合开始时的状态，$V$ 是叶子估值，$\tilde P$ 是[概览 §2](/arch/pimc/#sec-2) 的采样器。它执行 $\arg\max_a \hat Q(a)$，只执行这一个动作，然后重新观测战斗，再重新搜索。

这个公式里有两个要紧的选择：

- **最大值在每个世界内部取，平均在世界之间取**。如果在每个世界里分别取最好的动作，再在世界之间取最大值，计划就会表现得好像知道哪个世界才是真的。在同样的世界上取每个动作的平均，问的才是对的问题：不知道是哪个世界时，哪个动作最好。
- **只执行第一动作**。执行之后，紧接着的抽牌或掷骰就能看到，下一次搜索从新的观测开始。正是这一点把每个世界里的「先知」限制在一个回合的剩余部分之内（[§4](#sec-4)）。

## 3. 噪声与公共随机数

$\hat Q(a)$ 是 $K$ 个样本的均值，所以它的标准误是 $\sigma_a / \sqrt{K}$；决策日志记下每个第一动作的均值、95% 区间（$1.96$ 个标准误）以及它在每个世界里的值（[Harness：决策日志 §5](/arch/harness/decision-log/#sec-5)）。$K = 8$ 时区间很宽。不过，做选择需要的不是每个值本身，而是它们之间的差；而每个第一动作都在**同样的** $K$ 个世界上打分：这就是公共随机数（CRN）。对两个动作，

$$
\mathrm{Var}\big(\hat Q(a) - \hat Q(b)\big) = \frac{\sigma_a^2 + \sigma_b^2 - 2\rho\,\sigma_a \sigma_b}{K},
$$

所以当世界的运气让两个动作同涨同跌时（相关系数 $\rho$ 接近 1），它在差里就抵消了。

一个真实的决策能说明两种情况。冠军的一局 NoSL 对局（pimc c2 8×300，L0 v6-3-2；`promotion-1-300` 的 #0 号种子）遇到第 1 幕的精英骇鳗：第 1 回合，生命值 49/92，3 点能量，手牌七张，骇鳗即将攻击 16 点。每一行是一个第一动作；每个点是它在一个世界里的值，用叶子的单位；横条是它的 95% 区间。

- **扫腿**（给骇鳗 2 层虚弱，并获得格挡）是选中的动作，0.1708 ± 0.0113，领先其余约 0.02。
- **防御和切割**在每个世界里的值都相同，都是 0.1512：这是一个置换。无论先打哪一张，它之后的最好路线接着都打另一张，两者到达同样的状态。
- **涅奥之怒对打击**：它们的值在各个世界之间同涨同跌（相关系数 0.86）。它们的差是 0.0076，成对区间 ± 0.0035；如果用各自的世界，区间会是 ± 0.0094，宽到分不出两者。共用世界让差别变得清楚。
- **扫腿对带毒刺击**：它们的值此消彼长（相关系数 −0.73）。扫腿在五个世界里更好，带毒刺击在另外三个里更好，所以各世界对两者的先后看法不一。这里共用世界没有帮助（成对 ± 0.0168，不成对 ± 0.0131）：这个差是隐藏信息带来的真实变化，不是可以抵消的噪声。

## 4. 策略融合

在一个世界内部，搜索知道这个世界的未来。因此 PIMC 估计的量是 $\mathbb{E}_s\big[\max_\pi V\big]$：在看到世界*之后*才选出的本回合剩余的最好打法。玩家必须在看到之前就定下本回合剩下的打法，它值 $\max_\pi \mathbb{E}_s\big[V\big]$。最大值的均值从不小于均值的最大值（Jensen 不等式），所以 PIMC **会高估那些后面的选择取决于抽到或掷出什么的路线**：「先打计算下注，再看来什么」看起来比实际好，因为在每个世界里，搜索已经知道会来什么。这就是**策略融合**（strategy fusion）：计划把每个世界各自的一个策略融合成一个没有玩家能照着做的策略。

上面的表格在根节点上显示了同样的效应。勾选「标出每个世界里最好的第一动作」，就会标出每个世界里最好的第一动作：五个世界是扫腿，三个是带毒刺击。知道是哪个世界的玩家能得到每个世界最好值的平均，0.1734；PIMC 必须为所有世界选同一个动作，得到 0.1708。两者之间的 0.0026 是在这个决策上知道世界的价值，PIMC 正确地没有把它算进去。它确实算进去的融合，是低一层的同一个差距：在第一动作之后每个世界各自的路线里，对 $\pi$ 的最大值是逐个世界取的。

有两点让它保持较小。PIMC 只按第一动作汇总，也只执行第一动作，所以「先知」被限制在一个回合的剩余部分之内；而且它每执行一个动作就重新规划，到那时已经揭示的东西就不再是隐藏的了。

完全避免融合的替代方案是 **ISMCTS**（信息集蒙特卡洛树搜索）：在信息集（玩家无法区分的一组状态）上建一棵搜索树，每一轮采样不同的世界，所以树中的任何选择都不可能依赖隐藏信息。一次树模拟的开销约等于 3–4 个深度优先节点（估算）；而在信息大多公开的游戏里，考虑融合的 PIMC 变体改变不大：αμ 只改变了 1.3–3% 的决策，EPIMC 没有收益。所以 ISMCTS 留作后备，等测出融合确实要紧时再用。

测量它的是一个**融合测试集**（已实现：`fusion --log FILE[,…] [--k 32] [--max-nodes 5000]`）。它从决策日志里取 NoSL 战斗决策，多取回合内有揭示的局面，像 PIMC 那样以 $K$ = 32–64 构建它们的世界，把本回合完整枚举，然后对每个第一动作，比较 PIMC 给的值和按观测历史合并回传时的值（对动作取最大，对与该历史一致的世界取平均）。几个世界只在卡牌 id 上不同时，算作显示同样的观测，因为抽到的牌的 id 是它在那个世界洗牌后的位置。如果两者不一致的决策少于约 3%，损失又在噪声之内，就不做 ISMCTS。在两局的 36 个决策上先试了一次（$K$ = 16）：8 个有揭示，一个选择更差，平均损失 0.00002；一个复杂的回合约要一分钟。

## 5. 采样器的偏差

世界应当服从后验 $P(s \mid h)$，即给定所见一切时隐藏状态的分布。实际服从的是采样器的 $\tilde P(s \mid h)$：

- 抽牌堆均匀洗牌，这是精确的：没见过的牌的每种顺序都同样可能；
- 怪物排好的招在显示它意图的招里均匀抽取，不按掷骰的权重；
- 隐藏计数器（还要几回合才召唤、一招不断增长的伤害）没有后验，构建器只能尽量设定它们（[概览 §3](/arch/pimc/#sec-3)）。

更精确的采样器能减小这个偏差，而不用改搜索。保真度的数字说明了哪里值得做：回合结束之后，那几个出招取决于隐藏计数器的怪物上。
