[价值网络](/arch/macro-brain/network/)最后给出每层一个数。本节把这些数变成用来做决定的价值，然后反过来看：一个记录下来的决策怎样成为训练样本、损失是什么，以及一个网络怎样训练。

## 1. V 是什么

**V(s) = 由当前的冠军打下去时，从 s 赢下这一局的概率**。一个局面的 V，就是由*冠军*（目前已接受的最好的 AI 版本）打完剩下的部分时，这一局从那里赢下的概率。

- **一个尺度**。每个价值都是同一个事件的概率，所以休息处的一次回血、奖励里的一张牌和地图上的一条路径可以直接比较，不需要手写的换算比率（[后状态 §2](/arch/macro-brain/afterstates/#sec-2)）。
- **只用观测**。V 读整局观测，即玩家在战斗外看到的东西（[Harness：决策日志 §7](/arch/harness/decision-log/#sec-7)）。
- **两种环境共用一个 V**。SL 策略在之后的每个节点都打得比 NoSL 策略好，所以从同一个观测出发，它真实的胜率更高；共用的 V 有意忽略这一点（[环境：世界与两种战斗算法 §6](/arch/environments/worlds/#sec-6)）。V 用 SL 对局训练，其中的战斗由 SL 规划器来打。
- **依赖策略**。「由当前的冠军打下去」很要紧：同一个局面，在更强的玩家手里更值钱。这就是网络只用最新一代的对局训练的原因（[自我对弈 §4](/arch/macro-brain/selfplay/#sec-4)）。

## 2. 从风险值到价值

V 不直接预测胜率。它的输出头对 0 到 63 的每一层 $g$ 预测一个**风险值**

$$
h_g = P(\text{the run ends on floor } g \mid \text{it is still going on floor } g),
$$

这就是统计学里的离散时间生存模型（*风险值*（hazard）是在之前没有发生的前提下，事件在某个时刻发生的概率），这里由一个神经网络根据这一局算出每一层的风险值（和 Gensheimer 与 Narasimhan，2019 一样）。其余一切都由乘法得出。从这一局当前所在的第 $f$ 层起：

$$
S_g = \prod_{j=f}^{g} (1 - h_j), \qquad e_g = S_{g-1}\, h_g \quad (S_{f-1} = 1).
$$

$S_g$ 是过了第 $g$ 层仍在继续的概率，$e_g$ 是这一局恰好在第 $g$ 层结束的概率。于是：

- **P(win)** 是活过每一层的概率：$S_{63}$。赢下的对局被标为活过所有层（[§3](#sec-3)），所以这就是这一局赢下的概率。这就是 V 的价值：`RunNet.Value` 计算这个连乘。

为什么用风险值，而不是一个胜率输出：

- **每一层都有标签**。大多数对局是输的：冠军的 V 学习的对局里，大约每四局有三局输（[价值网络 §6](/arch/macro-brain/network/#sec-6)）。作为单个目标，大多数样本都只说「输了」。一个活过第 5 到 32 层、死在第 33 层的样本，对其中每一层都提供了信息。
- **中途停下的对局也算数**。被提前中止的对局（*删失*：在 `run --max-decisions` 处被截断）对它停下之后的各层什么也没说，掩码直接把这些层排除在外。单个目标就只能去猜。
- **整个分布**。同一个输出头给出这一局可能在哪里结束，报告可以读它。

为什么用胜率，而不是到达的层数：层数对每一层一视同仁，所以可能偏好一条稳稳走到第 2 幕的安全路线，而不是一条有时能赢的冒险路线。赢才是目标，而对局赢得够多，足以测量它。

## 3. 从记录下来的决策到样本

`learn/v/data.py` 构建样本。自我对弈日志里的每个宏观决策都是一个样本：这个决策处的整局观测（[Harness：决策日志 §7](/arch/harness/decision-log/#sec-7)），按对局 id 对上这一局的对局记录，记录里写着这一局在哪里结束（[评估：指标、种子与报告 §8](/arch/evaluation/metrics/#sec-8)）。失败对局的决策被排除。一次选路还给出第二个样本，即选中的点的后状态，因为 V 给地图选项估值时读的正是它，而记下的整局观测里都没有它（[价值网络 §4](/arch/macro-brain/network/#sec-4)）。它的目标是这一局真实的结局，即**蒙特卡洛（MC）目标**：没有估计，没有自举，只有实际发生的事。

一个样本包含：

- 它的**词元和数字**，从观测读出（[价值网络 §2](/arch/macro-brain/network/#sec-2)）。观测本身被丢弃：作为 Python 对象，观测大约大十倍。留出的样本把观测存为 JSON，用作网络文件的测试对局。
- 它的**起点** $s$，即观测的层数，以及它所在对局的**终点** $e$，即到达的层数，都最多为 63；
- 它所在对局的**类型**：死亡、赢下或删失；
- **接下来几场战斗的 HP 花费**，供第二个输出头用（[§4](#sec-4)）；
- 它的**权重**（[见下](#sec-3)）。

**标签：只用测到的东西**。对一个在第 $s$ 层取得、所在对局在第 $e$ 层结束的样本，每一层 $g$ 要么得到一个标签 $y_g$，要么没有标签：

| 这一局 | $g < s$ | $s \le g < e$ | $g = e$ | $g > e$ |
|---|---|---|---|---|
| 死在第 $e$ 层 | 无 | 0（活过） | 1（结束） | 无 |
| 赢了 | 无 | 0 | 0 | 0 |
| 在第 $e$ 层删失 | 无 | 0 | 无 | 无 |

例如，一局死在第 33 层的对局，它在第 5 层的决策有 29 个标签：第 5 到 32 层为 0，第 33 层为 1。一局赢下的对局，它在第 5 层的决策有 59 个标签：第 5 到 63 层为 0。

一个样本的**损失**是各有标签层上风险值的二元交叉熵，再加上第二个输出头的损失：

$$
\mathcal{L} = -\sum_{g \,\text{labelled}} \Big[ y_g \log h_g + (1 - y_g) \log(1 - h_g) \Big] \;+\; 3 \sum_{k} \big( \hat c_k - c_k \big)^2 ,
$$

其中 $c_k$ 是接下来第 $k$ 场战斗花掉的最大生命比例，$\hat c_k$ 是第二个输出头对它的预测。

**每一局权重相同**。一局里的所有决策共享一个结局，而一局的决策远超一百个。每个样本的权重是它所在对局决策数的倒数，所以一局长对局只算一次，而不是 180 次，一个批次的损失是加权平均。出于同样的考虑，AlphaGo 的价值网络每盘棋只取一个局面来训练（Silver 等，2016）：同一盘棋的局面高度相关，用全部局面训练的网络会把棋局背下来。

**按对局留出**。按对局 id 每五局留出一局（`int(run_id, 16) % 5 == 0`），连同它的全部决策，用于提前停止和报告。如果改为按决策划分，同一局的决策会落在两边，从而高估网络的表现。

<Aside>

**这里 MC 意味着什么**。标签是这一局在打它的那个策略下怎样结束的，包括决策之后的一切：战斗规划器的运气，以及自我对弈里后来的探索抽取（[自我对弈 §3](/arch/macro-brain/selfplay/#sec-3)）。所以它对那个策略是无偏的，对任何单个决策则噪声很大。

</Aside>

## 4. 第二个输出头

第二个输出头只在训练时使用，用六个 sigmoid 输出预测这一局接下来六场战斗各花掉多少比例的最大生命。死亡花掉剩下的全部；前方不到六场战斗的对局，只有现有那几场的目标。它的平方误差以权重 3 计入损失。

它从不用来做决定，也不在网络文件里。它的作用是塑造主干：一局里会多次测到战斗的 HP 花费，所以它给主干提供的目标比唯一的结局多得多，而且都关乎 V 必须判断的同一件事：这一局面对前方的战斗有多强。

## 5. 训练

```text
uv run python -m v.train --list PREFIX --name NAME [--init FILE]
```

`learn/v/train.py`。大小和设置写死在代码里，不是选项；做实验就在那里改，有结果才留下改动：

| 设置 | 值 |
|---|---|
| 层数 | 64，从第 0 层起 |
| 优化器 | AdamW，学习率 $3 \times 10^{-5}$，weight decay $10^{-4}$ |
| batch | 256 个样本，每轮重新打乱 |
| 轮数 | 最多 40 轮，连续 5 轮留出风险值损失没有降低 $10^{-4}$ 就停；保留最佳一轮的权重 |
| 词表 | 游戏的，固定不变（[价值网络 §2](/arch/macro-brain/network/#sec-2)） |
| 第二个输出头 | 权重 3 |
| 起点 | 风险值输出头的偏置设为基线（[见下](#sec-5)） |

**为什么学习率这么小，又从基线开始**。相对于数据量，结局很少，网络很快就会过拟合：它能在一轮之内背下一个局面来自哪一局。所以风险值输出头的偏置从训练对局里每一层的风险值开始，

$$
\frac{\text{deaths}_g + 0.5}{\text{alive}_g + 1},
$$

两个数都按样本的权重计数，网络只需学这一局怎样让每一层的风险值偏离这个平均值。它移动得足够慢，留出的对局才能说明何时该停。

**从一个网络接着训练（`--init`）**。训练可以从一个网络文件开始，而不是从零开始：沿用它的标准化参数和权重，权重从它的 ONNX 计算图读回（`export.weights`）。第二个输出头不在文件里，重新开始。这种结构的网络只能从这种结构的网络接着训练，词表与游戏不同的文件会被拒绝。

**在 GPU 上**，一个批次的张量先由样本构建成列表，再各变成一个张量。每次训练在一块 GPU 上运行。

## 6. 报告

训练器打印一份报告，并把它写进网络文件（`fit`）。全部都在留出的对局上测量：

| 字段 | 内容 |
|---|---|
| `runs`、`held_out_runs`、`samples`、`won` | 训练读了什么 |
| `vocab` | 每张词表的大小 |
| `held_out_loss`、`held_out_loss_floor_only` | 风险值的损失，以及只知道层数的基线的损失 |
| `held_out_next_combats` | 第二个输出头的误差 |
| `brier_held_out`、`brier_held_out_floor_only` | P(win) 的 Brier 分数：（预测的概率 − 赢下与否）² 的加权平均，以及基线的 |
| `won_held_out_runs` | 留出的对局中赢下了多少局 |
| `init_held_out_loss`、`init_brier_held_out` | 用 `--init` 时：起始文件在同样的留出决策上的风险值损失和 Brier 分数 |

Brier 分数衡量 V 区分不同对局的局面的能力。而一个决策只需要 V 把同一局面的各个选项排对顺序，这一点它衡量不了。所以每个网络都要靠实际对局来评判（[自我对弈 §5](/arch/macro-brain/selfplay/#sec-5)）。
