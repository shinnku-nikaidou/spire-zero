[价值网络](/arch/macro-brain/network/)最后给出每层一个数。本节把这些数变成用来做决定的价值，然后反过来看：每个训练样本的目标是什么、损失是什么，以及一个网络怎样训练。

## 1. 从风险值到价值

V 不直接预测价值。它的输出头对 0 到 63 的每一层 $g$ 预测一个**风险值**

$$
h_g = P(\text{the run ends on floor } g \mid \text{it is still going on floor } g),
$$

这就是统计学里的离散时间生存模型（*风险值*（hazard）是在之前没有发生的前提下，事件在某个时刻发生的概率），这里由一个神经网络根据这一局算出每一层的风险值（和 Gensheimer 与 Narasimhan，2019 一样）。其余一切都由乘法得出。从这一局当前所在的第 $f$ 层起：

$$
S_g = \prod_{j=f}^{g} (1 - h_j), \qquad e_g = S_{g-1}\, h_g \quad (S_{f-1} = 1),
$$

$S_g$ 是过了第 $g$ 层仍在继续的概率，$e_g$ 是这一局恰好在第 $g$ 层结束的概率。于是：

- **期望到达层数**。到达的层数是 $f$ 加上从 $f$ 起活过的层数，所以 $\mathbb{E}[F] = f + \sum_{g \ge f} S_g$。
- **P(win)**。当赢下的对局被标为活过每一层时（整局，[§2](#sec-2)），赢的概率就是活过所有层的概率：$S_{63}$。
- **进度**（精英连战的 V）。另一个输出头（比例头）对每一层给出**比例** $s_g$：这一局若在那里结束，结束时那场战斗里打掉的敌人生命比例。期望进度把它加到期望层数上：

$$
\mathbb{E}[\text{progress}] = \mathbb{E}[F] + \sum_{g \ge f} e_g\, s_g .
$$

`RunNet.Value` 正是这样计算的，网络文件里的 `objective`（`floor`、`win` 或 `progress`）说明三者中哪一个是 V 的价值。v6-3-2 的是 `progress`。

下图显示 v6-3-2 的输出头对一个局面给出的值。大多数层上风险值都很低，在第 2、3 幕的 Boss（第 33 和 48 层）处陡然升高：连战的对局就在那里结束。第 1 幕 Boss（第 17 层）只是一个小台阶，v6-3-2 在到达那里的对局中有 96% 能打赢它。生存曲线在每个尖峰处下降一级，第三张图是这一局在哪里结束的分布；它的均值加上各比例，就是进度。调低 HP，尖峰会变高。

为什么用风险值而不是一个数：

- **每一层都有标签**。一个活过第 5 到 32 层、死在第 33 层的样本，对其中每一层都提供了信息，而不只是「33」。这比单个回归目标的信号更密集。
- **中途停下的对局也算数**。被提前中止的对局（*删失*：被截断，或限时结束）对它停下之后的各层什么也没说，掩码直接把这些层排除在外（[§2](#sec-2)）。单个「到达层数」目标就只能去猜。
- **一个输出头，多种价值**。同一组风险值给出期望层数、P(win) 以及这一局在哪里结束的整个分布，所以目标可以换，而不用换网络（[§6](#sec-6)）。

<Aside>

**v6-3-2 没有 P(win)**。精英连战把*赢下*的对局标为结束在最后一层，比例为 1（最后一个 Boss 的生命全部打掉），所以它的进度是最后一层 + 1。因此第 48 层的风险值是「这一局在最后一个 Boss 处结束，不论输赢」，而对每个局面 $S_{63}$ 都接近 0。用「赢下的对局活过每一层」训练的整局 V，从同一个输出头读出 P(win)；那是下一个计划的目标（[弱点与下一步 §2](/arch/macro-brain/next/#sec-2)）。

</Aside>

## 2. 标签：只用测到的东西

自我对弈日志里的每个宏观决策都是一个训练样本：这个决策处的整局观测（[Harness §6](/arch/harness/#sec-6)），按对局 id 对上这一局的对局记录，记录里写着这一局在哪里结束（[评估 §6](/arch/evaluation/#sec-6)）。它的目标是这一局真实的结局，即**蒙特卡洛（MC）目标**：没有估计，没有自举，只有实际发生的事。

对一个在第 $s$ 层取得、所在对局在第 $e$ 层结束的样本，每一层 $g$ 要么得到一个标签 $y_g$，要么没有标签：

| 这一局 | $s \le g < e$ | $g = e$ | $g > e$ |
|---|---|---|---|
| 死在第 $e$ 层 | 0（活过） | 1（结束） | 无 |
| 赢了（整局） | 0 | 0 | 0 |
| 在第 $e$ 层删失 | 0 | 无 | 无 |

在精英连战里，结束了的对局不论输赢，都标为结束在它最后所在的那一层，比例头学这一层的比例：赢下的对局为 1，死在战斗里的对局为打掉的敌人生命比例，死在战斗之外的对局为 0。一个样本的损失是各有标签层上风险值的二元交叉熵，在连战里再加上它结束那一层上比例的交叉熵：

$$
\mathcal{L} = -\sum_{g \,\text{labelled}} \Big[ y_g \log h_g + (1 - y_g) \log(1 - h_g) \Big] \;-\; \Big[ \sigma_e \log s_e + (1 - \sigma_e) \log(1 - s_e) \Big],
$$

其中 $\sigma_e$ 是实际打掉的比例。下图用 v6-3-2 自己的风险值，为一个局面计算第一项：选择这一局怎样结束、在哪里结束，看看哪些层有标签，以及每一层给损失加了多少。

<LabelMask client:visible lang="zh-CN" start="test-4" />

**每一局权重相同**。一局里的所有决策共享一个结局。精英连战的一局，第 1 代平均有 108 个宏观决策，第 3 代有 146 个，所以第 3 代的 2,160,792 个决策只含 14,828 个结局。每个样本的权重是它所在对局决策数的倒数，所以一局长对局只算一次，而不是 180 次。出于同样的考虑，AlphaGo 的价值网络每盘棋只取一个局面来训练（Silver 等，2016）：同一盘棋的局面高度相关，用全部局面训练的网络会把棋局背下来。

**按对局留出**。按对局 id 每五局留出一局，连同它的全部决策，用于提前停止和报告。如果改为按决策划分，同一局的决策会落在两边，从而高估网络的表现。

**这里 MC 意味着什么**。标签是这一局在打它的那个策略下怎样结束的，包括决策之后的一切：战斗规划器的运气，以及自我对弈里后来的探索抽取（[自我对弈 §2](/arch/macro-brain/selfplay/#sec-2)）。所以它对那个策略是无偏的，对任何单个决策则噪声很大。

## 3. 第二个输出头

第二个输出头只在训练时使用，预测这一局接下来六场战斗各花掉多少比例的最大生命（死亡花掉剩下的全部；在连战里只算真打的战斗，即精英和 Boss）。它的平方误差以权重 3 计入损失。它从不用来做决定，也不在网络文件里。它的作用是塑造主干：一局里会多次测到战斗的 HP 花费，所以它给主干提供的目标比唯一的结局多得多，而且都关乎 V 必须判断的同一件事：这一局面对前方的战斗有多强。在 V v2 的数据上，用三个训练种子，它在每个种子上都降低了留出损失（平均 1.222 对 1.235），并提高了 $R^2$（0.384 对 0.371）。

## 4. 训练

`uv run python -m v.train`（`learn/v/train.py`）。大小和设置写死在代码里，不是选项；做实验就在那里改，有结果才留下改动：

| 设置 | 值 |
|---|---|
| 嵌入、单牌网络、主干 | 32、128、256 |
| 优化器 | AdamW，学习率 $3 \times 10^{-5}$，weight decay $10^{-4}$ |
| batch | 256 个样本 |
| 轮数 | 最多 40 轮，连续 5 轮留出损失没有改善就停 |
| 未知 id | 出现不到 3 次的 id |
| 第二个输出头 | 权重 3 |
| 起点 | 风险值输出头的偏置设为基线：训练对局里每一层的风险值，$(\text{deaths} + 0.5) / (\text{alive} + 1)$；比例头的偏置设为平均比例 |

**为什么学习率这么小，又从基线开始**。数据量虽大，结局却很少，网络很快就会过拟合。在 V v2 最初的数据（859 局）上，输出头随机初始化、学习率 $10^{-3}$ 的网络在一轮之内就把对局背下来了：第一轮后留出损失 1.331，第六轮后 4.12。从基线开始，同一个网络在 $10^{-3}$ 时达到 1.573，$10^{-4}$ 时 1.235，$3 \times 10^{-5}$ 时 1.229。从基线开始，网络只需学这一局怎样让每一层的风险值偏离平均值。

**从一个网络接着训练（`--init`）**。训练可以从先前的网络文件开始，而不是从零开始：沿用它的词表（它没见过的 id 读作未知）、标准化参数和权重，权重从它的 ONNX 计算图读回。第二个输出头不在文件里，重新开始。

**内存**。一个样本只保留它的词元和数字，不保留整局观测：作为 Python 对象，整局观测大约大十倍，第 3 代的 2,160,792 个决策在保留全部整局观测的训练里约占 117 GB，不保留时 20.9 GB。留出的样本把整局观测存为 JSON，用作网络文件的测试对局。

**报告**。训练器报告留出损失并与基线的对比，以及在留出对局上 V 的价值对实际达到的进度（或层数）的 $R^2$。第 3 代的结果：

| 网络 | 起点 | 留出损失 | $R^2$ | 最佳轮次 |
|---|---|---|---|---|
| 基线（每一层的平均风险值） | – | 1.9558 | 0.205 | – |
| v6-3-1 | 从零开始 | 1.7926 | 0.355 | 9 轮中的第 3 轮 |
| v6-3-2 | v6-2 的权重 | 1.7736 | 0.369 | 7 轮中的第 1 轮 |

$R^2$ 衡量 V 区分不同对局的局面的能力。而一个决策只需要 V 把同一局面的各个选项排对顺序，这一点 $R^2$ 衡量不了；所以每个网络都要靠实际对局来评判（[自我对弈 §4](/arch/macro-brain/selfplay/#sec-4)）。

## 5. 有用和没用的标签

在精英连战之前，纯 V 最初的几个网络（用 1,617 局整局）试过把模拟的 Boss 战当作额外的标签。每个都用 `promotion-1` 上的 200 局 SL 对局评判：

| 网络 | 额外标签 | 层数 | 配对差值 |
|---|---|---|---|
| pure-1 | 无 | 22.64 | 对随机局外决策 +7.35 ± 0.62 |
| pure-1-b | 每个卡牌奖励选项的牌组与本幕 Boss 对战（Boss 模拟） | 21.44 | 对 pure-1 −1.21 ± 0.67 |
| pure-1-d | 每一局在 Boss 门口的整套配置，按进门时的 HP 和三个最大生命比例对战（门口状态） | 24.77 | 对 pure-1 +2.12 ± 0.70 |
| pure-1-g | 另加 Boss 连战试点的门口状态（第 1–3 幕） | 25.69 | 对 pure-1-d +0.93 ± 0.58 |

实测的 Boss 战在描述这一局在门口的真实配置时有帮助，作为单个选牌的标签时则有害（模拟战斗的胜算和真实对局相差很远）。这个教训引出了精英连战：每一局都直接去打 Boss 和精英（[自我对弈 §1](/arch/macro-brain/selfplay/#sec-1)）。这些标签的细节见[学习 §2](/arch/learning/#sec-2)。

## 6. 由哪个目标做决定

V 的价值换过两次，每次都是因为前一个不再提供信息：

1. **期望层数**（`floor`）。只要没有一局能赢，P(win) 处处为 0，没有信号；到达的层数有。但它对每一层一视同仁，可能偏好一条稳稳走到第 2 幕的安全路线，而不是一条有时能赢的冒险路线。它只是权宜之计。
2. **期望进度**（`progress`，精英连战）。连战的对局大多结束在 Boss 处，所以只看层数分不出打掉 Boss 60% 生命的对局和只打掉 10% 的对局；比例可以。
3. **P(win)**（`win`），一旦对局偶尔能赢。用 v6-3-2 的整局 SL 对局 300 局赢 23 局，所以条件已经满足，下一个计划训练一个按 P(win) 做决定的整局 V（[弱点与下一步 §2](/arch/macro-brain/next/#sec-2)）。
