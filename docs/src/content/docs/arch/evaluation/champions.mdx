**冠军**是 AI 在一种环境里已接受的最好版本：各个大脑、它们的预算和权重，以及代表它们的那份报告。本页是一份记录：指明冠军的文件，迄今为止的每个冠军以及它是怎么成为冠军的，没有带来晋级的门槛，以及其他项目和我们自己的各代达到了什么成绩。门槛如何运作见[晋级门槛](/arch/evaluation/gates/)。

## 1. 冠军文件

`eval/CHARACTER/champions/ENV.json`（`nosl.json`、`sl.json`）为每个角色、每种环境存一个冠军，格式是 `ChampionFile` 记录（`Harness/Gate.cs:116-117`）。今天的 SL 冠军文件：

```json
{
  "env": "SL",
  "champion": "combat plan c2 beam 8x300 easy 4 loss plans 3, combat prompts p0, macro l0 v6-3-2 clone, macro prompts l0 v6-3-2 clone",
  "options": {
    "env": "SL", "policy": "plan", "macro": "l0", "effort": "medium",
    "value": "weights/silent/v6-3-2.json", "afterstates": "clone", "combat-net": "weights/silent/c2.json",
    "character": "SILENT", "asc": "0"
  },
  "report": "eval/silent/reports/2026-10-30-sl-r1-promotion-1-300-plan-c2-l0-v6-3-2-clone-p0.json",
  "since": "2026-10-30"
}
```

（在文件里是一行，这里展开了。）

| 字段 | 内容 |
|---|---|
| `env` | `NoSL` 或 `SL`；挑战者的 `--env` 与它不同时，门槛会拒绝 |
| `champion` | 报告里显示的冠军名字，即路由表每一侧的大脑加上预算（[Harness：路由、预算与种子 §1](/arch/harness/routing/#sec-1)） |
| `options` | 打出这个冠军的对局选项，去掉了 `--`，其中包括角色和进阶等级；权重文件用它在 `weights/CHARACTER/` 里的路径表示 |
| `report` | 与挑战者配对的报告：每道门槛的冠军一方 |
| `since` | 成为冠军的日期（晋级报告的日期，或手写的日期） |
| `gate` | 它通过的门槛，没有经过门槛就确定的冠军没有这一项：`metric`、`delta`、`alpha`、`beta`、`pairs`、`decided`、`llr`、`lower`、`upper`、`floor_diff_mean`、`challenger_only_wins`、`champion_only_wins`、`verdict`，有的话还有 `void_reason`，以及 `not_worse`（从 `a2643cf` 起的文件里才有；这个字段随不更差门槛 `62876d4` 一起加入） |

**谁读取它**。

- `run`、`brain`、`afterstates` 和 `fork` 接受 `--champion FILE`，打它指明的冠军（`SimWorker/Commands/Args.cs:173-202`，[模拟器：参考 §3](/arch/simulator/reference/#sec-3)）。文件里的选项排在命令行给出的选项之后，所以给出的优先；命令没有的选项会被跳过（`brain` 没有 `--env`：每个宿主自己指明）；给出的 `--policy` 若与文件里的不同，就保留它自己的预算。
- `gate --champion FILE` 是要击败的冠军：它读取文件的 `env` 和 `report`（[晋级门槛 §6](/arch/evaluation/gates/#sec-6)）。`learn/challenge.py` 读取报告的种子集、种子集的大小、角色和进阶等级。
- `leaderboard` 在文件所属环境的榜上，标出每个文件指明的报告（[指标、种子与报告 §9](/arch/evaluation/metrics/#sec-9)）。

**由 `--promote` 写入，或手工写入**。`gate --promote` 写入每一个字段，选项按挑战者的选项生成（`ChampionOptions.Options`，`SimWorker/Brains/ChampionOptions.cs:86-114`）：对 SL 规划器来说是 `beam`、`easy-beam`、`replan`、`loss-plans` 和 `nodes`，而不是 `effort`。还没有哪个 SL 冠军是由 `gate` 晋级的；SL 文件是手写的，写的是 `"effort": "medium"`，打的是同样的预算（[SL 规划器：预算 §1](/arch/sl-planner/budget/#sec-1)）。重定基线只修改 `report`（[晋级门槛 §9](/arch/evaluation/gates/#sec-9)）。

**现在**。自 2026-10-30 起，两个文件都指明 `weights/silent/v6-3-2.json`、`weights/silent/c2.json` 和上面那份报告，没有门槛。SL 打的是 medium 力度的 SL 规划器，加上在克隆上的 L0；NoSL 打的是 8 个世界 × 300 个节点的 PIMC，加上用按画面所示的后状态的 L0（`"policy": "pimc", "worlds": "8", "nodes": "300"`）。NoSL 文件指向的是 SL 报告，因为这个冠军还没有 NoSL 报告；针对它的 NoSL 门槛会被拒绝（[评估 §3](/arch/evaluation/#sec-3)）。

- **先是搜索，然后是宏观大脑**。在 NoSL 的 `promotion-1` 上，宏观大脑不变，PIMC 把层数从 11.90（`play`）提到 19.34；把 c2 作为它的叶子，提到 21.88；宏观大脑里换上学到的 V，提到 23.96 和 26.16。在 SL 下，规划器把 n2-b0.03 的 26.16 提到 28.25；连战训练出的 V 在克隆上，提到 31–33.6，并有了最初的胜局。自 2026-10-28 起战斗大脑没有变过：此后的提升都来自宏观大脑（[SL 规划器：预算 §5](/arch/sl-planner/budget/#sec-5)）。
- **对局在哪里结束**。在打到 Boss 的对局里，v6-3-2 打赢第 1 幕 Boss 的占 95%，第 2 幕 Boss 55%，第 3 幕 Boss 35%。它的 277 局输局中，133 局在 Boss 战，39 局在精英战，103 局在普通怪物战，2 局在战斗之外（[指标、种子与报告 §8](/arch/evaluation/metrics/#sec-8)、[宏观大脑：弱点与下一步 §1](/arch/macro-brain/next/#sec-1)）。
- **第一个角色是静默猎手，先做 A0**。每个角色有自己的文件夹，`eval/CHARACTER/`、`weights/CHARACTER/` 和 `data/CHARACTER/`，所有进阶等级共用一个大脑（[学习：参考 §3](/arch/learning/reference/#sec-3)）；`eval/seeds/` 里的种子集是共用的。
