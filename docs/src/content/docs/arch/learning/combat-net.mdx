战斗网络是战斗搜索学到的叶子：从一个回合的开始，它预测在打出它训练对局的那个策略下，这场战斗会怎样结束。它读什么、它的各层怎样组合这些输入，见[战斗网络](/arch/combat-brain/network/)；搜索怎样用它的输出，见[叶子](/arch/combat-brain/leaf/)。本页讲它怎样训练、用哪些数据，以及训练出的网络测出了什么。

## 1. 它预测什么

从一个回合的开始，预测两样东西：

- **结局**：51 个类别上的分布，即一个死亡，或者从这个状态起还要失去的最大生命值比例的 50 个分桶之一，持有的生命值排除掉的分桶是关闭的。
- **药水**：赢下之后，每瓶持有的药水没有了的概率。

`learn/combat/` 训练它（`combat.train`，`learn/combat/train.py:40`）。`--combat-net FILE` 让它来打，用在 SL 规划器里（显示为 `plan NAME`）或 PIMC 里（`pimc NAME`）。

## 2. 它读什么

全部内容见[战斗网络 §2](/arch/combat-brain/network/#sec-2)。`learn/combat/encode.py` 是唯一的规格，`CombatNet` 在 C# 里遵循它。

## 3. 样本与标签

`learn/combat/data.py` 从一份决策日志和对局记录的清单生成样本，每个角色的都读（[参考 §4](/arch/learning/reference/#sec-4)）。

- **一个样本是一个回合的开始**：日志里每个回合的第一个战斗决策，也就是搜索叶子所处的那种状态，因为搜索的叶子就是下一回合的开始（[叶子 §1](/arch/combat-brain/leaf/#sec-1)）。一场战斗的决策在下一个宏观决策处结束，或者在回合数倒退时结束；选牌提示的行被跳过（`combats`，`learn/combat/data.py:33-67`）。
- **在它之前敌人的历史**由更早各回合的开始重建，每个活着的敌人的意图按它的 uid 对应，与 Harness 的 `Dispatcher` 构建它的方式相同（`witness`，`learn/combat/data.py:70-77`）。
- **结局的标签相对于这个状态**：一个死亡，或者这个状态的生命值比例减去战斗结束时的比例所落入的分桶（`ending`，`learn/combat/data.py:97-102`）。回血超过最低分桶时落入最低分桶。所以一场战斗的每个回合开始都有同一个结束，却各有自己的标签。这是蒙特卡洛：它是打出它的策略下真实发生的事（[循环 §3](/arch/learning/loop/#sec-3)）。
- **药水的标签**来自战斗后的第一个整局观测，逐瓶计算：这个状态持有、而那里没有的药水算作没有了（`potions_used`，`learn/combat/data.py:80-90`）。不取自动作，因为动作会漏掉没有动作就消耗的瓶中精灵，占所有没有了的药水的 6.2 %。也不取自最后一个回合的开始，因为它会漏掉最后一个动作喝掉的药水。战斗后来得到的药水不是这个状态的药水。死亡只训练结局。
- **不用的数据**（`read`，`learn/combat/data.py:131-157`）：失败的对局；记录中没有 `end` 的战斗，除非它是一局输掉的对局的最后一场，那样算作死亡；赢下之后没有整局观测的战斗；还有日志中的战斗与记录在数量或遭遇上对不上的每一局，训练器会计数并报告。
- **一种环境**。`--env SL|NoSL` 只读那种环境的行；另一种环境的日志行会让训练失败。这个网络用 `--env SL` 训练（[叶子 §6](/arch/combat-brain/leaf/#sec-6)）。
- **权重与划分**。每个回合开始的权重相同，按对局 id 每五局留出一局，连同它所有的回合开始，用于提前停止和报告。每 1,000 个留出的回合开始中有一个保留观测和历史，用作网络文件的测试状态（`KEEP`）。

**数据**。冠军的权重最近一次学自进阶 10 的整局 SL 自我对弈，即 `v8g2` 的 10,038 局，每场战斗都打了，用中等预算。合计 736,075 个回合开始，其中 153,718 个留出。自我对弈和晋级门槛的种子从不相遇，`--list` 也拒绝含有评估作业对局的清单（`common.train_lists`）。c8-3 接着 c8-2 训练，c8-2 学自 `v8g1` 的 8,087 局 A10 对局，接着 c8-1 训练，而 c8-1 的权重学自进阶 0：21,263 局自我对弈，大多用低预算（[SL 规划器：预算 §2](/arch/sl-planner/budget/#sec-2)），加上种子 `promotion-301-500` 上 600 局中等预算对局，所以 `promotion-1-500` 不再用作测试集（[评估：指标、种子与报告 §5](/arch/evaluation/metrics/#sec-5)）。

在这些权重的 `c7` 集上，胜利的回合开始中，掩码从不关闭真实的分桶，1,479,991 个中有 98 个回血超过最低分桶。9.4 % 的回合开始持有药水。

## 4. 损失与训练

```bash
uv run python -m combat.train --list data/silent/lists/v8g2 --env SL --name NAME --test-list data/silent/lists/medium
```

一个样本的损失是（`loss`，`learn/combat/net.py:326-333`）

$$
\text{loss} = \text{CE}(\text{masked endings}, \text{class}) + \text{won} \sum_{\text{held}} \text{BCE}(u_{\text{id}}, \text{gone}).
$$

药水项的权重是 1（`POTION_WEIGHT`），约占损失的 1 %：每个胜利样本 0.051 行药水，每行约 0.33 nats，而交叉熵约为 1.24。所以主体仍然属于结局。

设置写死在代码里（`learn/combat/train.py:34-36`）：AdamW，学习率 10⁻³，权重衰减 10⁻⁴；batch 256；最多 20 轮，连续 3 轮留出损失没有降低 10⁻⁴ 就停止。做实验就改代码，只有出了结果才留下改动。词元表是游戏的，固定不变（[战斗网络 §2](/arch/combat-brain/network/#sec-2)）。

**从一个网络接着训练（`--init FILE`）**。训练可以从一个网络文件的权重开始，权重从它的 ONNX 计算图读回（`export.weights`），学习率降为 3 × 10⁻⁴。除非某一轮的留出损失比文件的权重低，否则文件的权重保持不变。词元表与游戏不同的文件会被拒绝。c8-3 就是这样从 c8-2 接着训练的，只用 `v8g2` 的 10,038 局：最好的是 6 轮中的第 2 轮，留出损失从 c8-2 的 1.2913 降到 1.2579。

**报告**（`learn/combat/report.py`）是 stdout 上的一行 JSON，也保存为网络文件的 `fit`：`env`、`runs`、`held_out_runs`、`samples`、`held_out_samples`、`vocab`，然后是 `held_out`，以及同样内容按幕、房间、遭遇、生命值（是否低于 30 %）和药水 id 分开。有 `--test-list` 时，`medium` 对整份清单给出同样内容，这些对局只报告，从不训练。

| 字段 | 说明 |
|---|---|
| `ce`、`ce_prior` | 结局的交叉熵，以及训练集频率的交叉熵 |
| `death`、`predicted_death` | 实际和预测的均值 |
| `rank_lost`、`rank_lost_share` | 在每个 10 个或更多样本的 (遭遇, 回合) 内，与胜利时失去的生命值的等级相关，按大小加权；旁边是生命值比例的：网络在持有的生命值之外增加了什么 |
| `auc_death`、`auc_death_share` | 在每个死亡和存活各有 3 个或更多的 (遭遇, 回合) 内，死亡的回合开始得分高于存活的概率；旁边是生命值比例的 |
| `potions` | `rows`、`used`、`predicted`、`log_loss`，以及 `log_loss_id` 和 `log_loss_id_room`，即按 id、按 id 和房间的比率给出的对数损失 |

**网络文件**写到 `weights/all/NAME.json`，从不覆盖（[参考 §6](/arch/learning/reference/#sec-6)）。它的字段见[参考 §7](/arch/learning/reference/#sec-7)。

## 5. 它测出了什么

这些数是 `weights/all/c9-1.json` 里的报告。「留出」是训练清单中每五局的一局，共 6,004 局全部五个角色在进阶 0 的对局，407,042 个回合开始，用低预算打。

| 指标 | 留出 | 只用生命值比例 |
|---|---|---|
| 结局的交叉熵（先验的） | 1.249 (2.352) | – |
| 死亡，实际和预测 | 9.27 %、10.03 % | – |
| 胜利时失去生命值的等级相关 | 0.727 | 0.121 |
| 死亡的 AUC | 0.957 | 0.679 |
| 药水的对数损失（按 id 和房间的） | 0.340 (0.564) | – |

**怎么读**。失去生命值的等级相关和死亡的 AUC 是网络在持有的生命值之外增加的东西，所以各自都和生命值比例自己的数并列。一局怎样看待各个结局的价值，是 V 的事，不是这份报告的（[战斗大脑：叶子 §5](/arch/combat-brain/leaf/#sec-5)）。

按房间，在留出对局上：

| 房间 | 回合开始 | 交叉熵（先验） | 死亡，实际和预测 | 失去生命值的等级相关 | 死亡的 AUC（生命值比例） |
|---|---|---|---|---|---|
| 普通战斗 | 264,191 | 0.988 (1.958) | 0.9 %、1.0 % | 0.702 | 0.973 (0.848) |
| 精英战 | 66,949 | 1.786 (2.955) | 9.6 %、10.1 % | 0.784 | 0.968 (0.728) |
| Boss 战 | 75,902 | 1.684 (3.191) | 38.2 %、41.4 % | 0.792 | 0.953 (0.655) |

**低生命值**，即低于最大生命值的 30 %，那里留出的回合开始有 27.3 % 会死：死亡的 AUC 是 0.945，生命值比例是 0.519。

**按 id 看药水输出头**。在留出对局上，瓶中精灵有 17.7 % 的时候用掉，预测为 18.9 %，对数损失是 0.155，而按 id 和房间的是 0.381。在所有行上，31.2 % 用掉，预测为 32.1 %。

**最难的战斗**。在知识恶魔上，留出的回合开始有 53.2 % 会死，网络预测 55.3 %，死亡的 AUC 是 0.970，生命值比例是 0.675。胜利时失去生命值的等级相关是 0.799，生命值比例是 0.116。

**对比它接着训练的那个网络**。在同样的留出回合开始上，只学过静默猎手对局的 c9-0 损失是 4.33，c9-1 是 1.27。差距来自其他角色：静默猎手的回合开始从 1.27 变到 1.20，铁甲战士的从 9.72 变到 1.54，储君的从 5.87 变到 1.23，亡灵契约师的从 4.34 变到 1.13，故障机器人的从 4.17 变到 1.30。

这些当中哪些能变成更多赢下的对局，由门槛来说（[评估：晋级门槛 §5](/arch/evaluation/gates/#sec-5)）。配 V v9-1，在进阶 0、中等预算下，它用铁甲战士、储君、故障机器人和亡灵契约师在 100 局中分别赢下 46、35、31 和 9 局，而 v9-0 配 c9-0 赢下 1、2、1 和 0 局；用静默猎手赢下 74 局，此前是 86 局（[评估：冠军与基线 §2](/arch/evaluation/champions/#sec-2)）。
