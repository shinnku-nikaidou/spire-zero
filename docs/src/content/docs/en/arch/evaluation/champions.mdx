A **champion** is the best accepted version of the AI in one environment: the brains, their budget and their weights, and the report that stands for them. This page is the record: the file that names a champion, every champion so far and how it got there, the gates that did not promote, and what other projects and our own generations have reached. How gates work is on [Gates](/en/arch/evaluation/gates/).

## 1. The champion file

`eval/CHARACTER/champions/ENV.json` (`nosl.json`, `sl.json`) holds one champion per character and environment, as the `ChampionFile` record (`Harness/Gate.cs:116-117`). The SL champion's file today:

```json
{
  "env": "SL",
  "champion": "combat plan c7-2 beam 8x300 easy 4 loss plans 3, combat prompts p0, macro l0 v7-1f clone, macro prompts l0 v7-1f clone",
  "options": {
    "env": "SL", "policy": "plan", "macro": "l0", "effort": "medium",
    "value": "weights/silent/v7-1f.json", "afterstates": "clone", "combat-net": "weights/silent/c7-2.json",
    "character": "SILENT", "asc": "0"
  },
  "report": "eval/silent/reports/2026-10-31-sl-r1-promotion-1-100-plan-c2-l0-v7-1f-clone-p0.json",
  "since": "2026-10-31"
}
```

(one line in the file, spread out here).

| field | what it holds |
|---|---|
| `env` | `NoSL` or `SL`; a gate refuses a challenger's `--env` that is not this |
| `champion` | the champion's name as the reports show it, the brains on each side of the routing table with the budget ([Harness: routing, budgets and seeds §1](/en/arch/harness/routing/#sec-1)) |
| `options` | the run options that play it, without their `--`, the character and ascension among them; weights files by their path in `weights/CHARACTER/` |
| `report` | the report a challenger is paired with: the champion's side of every gate |
| `since` | the date it became champion (the promoted report's date, or the date written by hand) |
| `gate` | the gate it passed, absent for a champion set without one: `metric`, `delta`, `alpha`, `beta`, `pairs`, `decided`, `llr`, `lower`, `upper`, `floor_diff_mean`, `challenger_only_wins`, `champion_only_wins`, `verdict`, `void_reason` when there is one, and `not_worse` (in the files from `a2643cf` on; the field came with the not-worse gate, `62876d4`) |

**Who reads it.**

- `run`, `brain`, `afterstates` and `fork` take `--champion FILE` and play the champion it names (`SimWorker/Commands/Args.cs:173-202`, [Simulator: reference §3](/en/arch/simulator/reference/#sec-3)). The file's options come after the ones given, so given ones win; an option the command does not have is skipped (`brain` has no `--env`: each host names its own); a `--policy` given that is not the file's keeps its own budget.
- `gate --champion FILE` is the champion to beat: it reads the file's `env` and `report` ([Gates §6](/en/arch/evaluation/gates/#sec-6)). `learn/challenge.py` reads the report's seed set, size, character and ascension.
- `leaderboard` marks the report each file names, on the board of the file's environment ([Metrics, seeds and reports §9](/en/arch/evaluation/metrics/#sec-9)).

**Written by `--promote`, or by hand.** `gate --promote` writes every field, the options as the challenger's options make them (`ChampionOptions.Options`, `SimWorker/Brains/ChampionOptions.cs:86-114`): for the SL planner that is `beam`, `easy-beam`, `replan`, `loss-plans` and `nodes`, not `effort`. No SL champion has been promoted by `gate`; the SL files were written by hand and say `"effort": "medium"`, which plays the same budget ([The SL planner: budget §1](/en/arch/sl-planner/budget/#sec-1)). Re-baselines edit only `report` ([Gates §9](/en/arch/evaluation/gates/#sec-9)).

**Now.** Both files name `weights/silent/v7-1f.json` and `weights/silent/c7-2.json`. The report named above was played with an earlier combat net; it stands until a report of this champion exists. SL plays the SL planner at medium effort with L0 on the clone; NoSL plays PIMC with 8 worlds × 300 nodes and L0 with screen afterstates (`"policy": "pimc", "worlds": "8", "nodes": "300"`). The NoSL file names the SL report, since no NoSL report of this champion exists; a NoSL gate against it is refused ([Evaluation §3](/en/arch/evaluation/#sec-3)).

**What the table shows.**

- **Search, then the macro brain.** On `promotion-1` in NoSL, PIMC took the floor from 11.90 (`play`) to 19.34 with the same macro brain; c2 as its leaf to 21.88; learned V's in the macro brain to 23.96 and 26.16. - **Where runs end.** v6-3-2 beats the act 1 boss in 95% of the runs that reach it, the act 2 boss in 55%, the act 3 boss in 35%. Of its 277 losses, 133 are at a boss, 39 at an elite, 103 in a monster fight and 2 outside combat ([Metrics, seeds and reports §8](/en/arch/evaluation/metrics/#sec-8), [Learning: the experiment log §10](/en/arch/learning/experiments/#sec-10)).
- **The first character is the Silent, and A0 comes first.** Each character has folders of its own, `eval/CHARACTER/`, `weights/CHARACTER/` and `data/CHARACTER/`, and one brain for all its ascensions ([Learning: reference §3](/en/arch/learning/reference/#sec-3)); the seed sets in `eval/seeds/` are shared.

## 6. Open questions

1. **R4 throughput:** how many minutes one run takes at the game's Instant speed, and so how many R4 runs are affordable.
2. **The wins gate at few discordant seeds:** plan v7's bound passes 3 wins against none ([Gates §10](/en/arch/evaluation/gates/#sec-10)); whether to require a minimum of discordant seeds, or an exact test, once the first gates show how many there are.
3. **The gates' error rates:** neither gate's false-pass rate has been measured; an A/A test needs a way to vary the champion's own randomness alone ([Gates §4](/en/arch/evaluation/gates/#sec-4)).
4. **A NoSL report of the champion**, so that the NoSL board has a champion again and SL − NoSL can be measured for one V.
5. **`final-1`**: when the first formal claim is made on it.
