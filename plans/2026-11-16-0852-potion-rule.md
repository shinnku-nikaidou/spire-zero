  - 複製劑喝了之後同回合沒出牌：6 %（就是用戶看到的那一手）。
- 來源：2026-11-07 以前，地圖上的藥水選項和移動不是同一個尺度，self-play 丟掉 69–79 % 的藥水，V 學到「藥水比空格差」。
  當時只改了下法規則，網路一路 `--init` 帶下來；後來的資料又是同一批偏見的 V 下的，所以只慢慢回升。
- 資料裡其實有訊號：v10g1 的 FOOL 在 A0–A9 只用均勻 ε 抽樣，抽到「拿」的比抽到「不拿」的多活 1.2 ± 0.16 層。

## 3. 規則（只在生成時用，冠軍檔和 mod 不變）

### R1 + R2：免費丟棄（用戶的想法：別讓網路的輸出把藥水的分支直接剪掉）

遊戲裡藥水隨時能免費丟掉，所以有藥水的腰帶不可能比沒有的差。生成時，每次給 run 定價都取「丟掉其中任意幾瓶」裡最好的值：

    V'(run) = max over S ⊆ belt of V(run with only S)

- 拿藥水（R1）：**用戶 2026-11-16 09:00 下令，實戰和生成都一樣：「嚴禁還有位置的時候不拿藥水」。已經做了，不等 v11。**
  `MacroBrain.Offered` 在獎勵畫面上還有藥水可拿（遊戲只在有空格時列出它）時，不提供 proceed。
  根決策、clone 的搜尋（`CloneSearch.Answers`）、探索的抽樣都經過 `Offered`，所以三處一致。
  腰帶滿的時候遊戲不列出那瓶藥水，proceed 照常，換不換仍然由 V 決定（`Offered` 允許丟一瓶騰位置）。
  測試：`MacroPotionTests.APotionTheBeltHasRoomForIsTaken`。免費丟棄在這裡已經不需要。
- 什麼時候喝（R2）：留著藥水的路線，分數不會低於「白喝掉」的路線，所以留在束裡。
  到了某一回合用得上時，那條線就贏；用不上，就留到下一場。
  這就是「大量搜尋不同回合使用藥水的路徑」：束本來就會在每回合試喝，現在不會因為 V 的偏見把留著的路線先剪掉。
- V 喜歡的藥水（仙女 +8 個勝率點、虛弱、迅捷）照樣有正價值，不被抹平。這裡沒有任何手寫分數，只用了遊戲的一條規則。
- 實作：
  - `src/Sts2Ai.Brain/Macro/` 加一個 `FreeDisposal : IRunValue`，包住 V。
  - `src/Sts2Ai.SimWorker/Brains/LeafChoice.cs` 的 `Read` 是 L0 和戰鬥網共用 V 的唯一地方：給了 `--free-disposal` 就包起來。
    `WorkerOptions` 把這個選項傳給搜尋 worker；brain 的名字帶上記號，記錄的 config 裡看得到。
  - 戰鬥葉子本來就對持有藥水的每個子集合問 V（CombatNet.Priced 的 masks），價格有快取。
- 要驗的細節：
  - 平手時束要留下「還拿著藥水」的那個狀態，要有測試。
  - V 的呼叫次數最多變成 2^k 倍（k = 持有瓶數，A10 是 2–3 格），要量每局的時間。

### R3：小怪戰的保留抽樣（用戶 2026-11-16 08:57：現在就加，不等 smoke）

用戶的日誌顯示「留到菁英、頭目」比冠軍多得多。R1 + R2 之後，V 不喜歡的藥水只值空格，規劃器在小怪戰只要省到一點 HP
就會喝。R3 讓資料裡有「留到後面」的反事實，V 才學得到留著值多少。

- **抽什麼**：每場小怪戰（Monster 房）開打時抽一次，以機率 q 抽中「這場不准喝藥水」。種子從 run id 和決策序號來，和
  其他抽樣一樣，不從遊戲來。菁英和頭目戰不抽。
- **q = 0.5，每一個 ε 層都一樣**（我定的，見下）。理由：每場抽一次，兩邊一樣多，同一批資料裡就能直接比
  「這場留著」和「這場能喝」。q 太小，留著的那邊樣本太少。比 0.5 大，又把用戶那種「辛苦的小怪戰才喝」
  （有喝的小怪戰掉 9.4 % 最大 HP，沒喝的 4.4 %）壓得太少。
- **會死就解除**：抽中的那場，如果不准喝時規劃出來的最好路線是輸（`SlPlan.End == Lost`），就解除這次抽中，
  准喝重新規劃。用戶也會在打不過的小怪戰喝。抽樣只是要資料，不該讓一個抽中直接殺掉一局。解除也記下來。
- **實作**：
  - `SlRoute`（src/Sts2Ai.Brain/Combat/SlPlanner.cs）每局一個，它知道一場戰鬥的第一個計畫。抽在那裡做。
  - 抽中時，計畫的 budget 帶一個「不准喝」的旗標，`SlPlanner.SearchTurn` 生成動作時把 `UsePotion` 拿掉。
  - 旗標隨 budget 送到 pooled 的 worker，Rust 引擎那邊不用改：動作清單是 C# 這邊給的。
  - 選項：`--potion-reserve Q`，和 `--free-disposal` 一起寫進 dataset toml。
- **記錄**：這場戰鬥的第一個戰鬥決策記一個 `reserve: true`（解除時 `reserve: lifted`），分析時才分得開。
  `learn/` 不讀 `explored` 也不讀這個欄位，訓練照常：V 的標籤是整局的結果，戰鬥網的標籤是這場的結局。
- **不手寫「只在頭目喝」**：那是策略，而且是多人局的策略。R3 只是隨機地讓一半的小怪戰不准喝，什麼時候喝最好由資料教。

### 不做的

- 不給藥水手寫價格（2026-11-07 以前的教訓，大道至簡）。
- 不模仿多人日誌：100 局，而且是另一種遊戲。
- `Offered` 在實戰照舊。生成時有了 R1 + R2，它已經沒事可做。
- 不在菁英、頭目戰抽 R3：用戶在那裡喝得最多（菁英 41–53 %、頭目 65–77 % 的戰鬥有喝）。

## 7. 惡臭藥水（用戶 2026-11-16：禁止戰鬥時丟；研究怎麼偏向走商店，到商店先丟）

遊戲規則（反編譯的 v0.113.1，`FoulPotion`、`PotionCourier`、`FakeMerchant`、`NMerchantRoom`）：

- 來源主要是第二幕起的「藥水信使」事件：拿藥水給 3 瓶惡臭藥水（有空格才拿得到），或搜刮給 1 瓶罕見藥水。
  另外也在事件藥水池裡。
- 戰鬥中：對**所有**生物（寵物除外）造成 12 點傷害，玩家自己也吃。
- 戰鬥外：只能在商店（商人的商品欄關著的時候）丟給商人，每瓶 +100 金，沒有次數限制，沒有壞處。
  或者丟給假商人（第二幕起、單人、金幣 ≥ 100 或身上有惡臭藥水才會出現），會開打，贏了拿假商人的地毯和它的假遺物。

AI 今天怎麼用：

- v10g1 A0–A9：開戰時拿著的，98–100 % 在那場就丟了（285 次，94 % 丟完同回合沒出牌，每次自己吃 12）。
  在商店丟給商人只有 51 次。
- 冠軍 v10-2-2 的 A10 測試：在獎勵畫面丟掉 32 瓶。
- V 在所有狀態上都把它評得比空格低（100 %）。在它訓練的資料裡，拿著它就等於下一場戰鬥自己吃 12，這個評價對那份資料是「對的」。
- 有空格必拿（R1）之後，信使的三瓶都會被拿，所以戰鬥禁丟必須一起上。

偏向走商店（提議，等用戶）：

- F3a 進商店的後狀態算上丟出去的錢：地圖移動的後狀態（`ScreenAfterstates.Entered`）進入商店點時，
