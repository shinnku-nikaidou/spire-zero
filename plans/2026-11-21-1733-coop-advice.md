## Goal

In a real co-op run with people (2 to 4 players, teammates without the mod), the panel shows the local player the
brain's answer for their own seat, as in a single-player run: the recommended action, each option's numbers, and the
fight details card. The AI never acts in a run of more than one player: no auto, no step buttons, no console command
that plays. The game sees nothing from us but what it already sees from a mod that only reads (`affects_gameplay:
false`), so the lockstep checksums cannot diverge.

## Where it stands at HEAD (1.0.0)

- A hidden console switch `ai mp on` (Assist.Multiplayer, kept for the game session) serves multiplayer runs; off, the
  panel says "Off in multiplayer".
- A multiplayer run is NoSL whatever the panel's switch says (Assist.cs, Tick): no clone holds the teammates' choices.
- Screens.Waits: in a multiplayer run a card prompt in a fight is "answer the card prompt yourself", and a map, event or
  treasure vote already cast is "waiting for teammates"; Mend is taken out of the rest site's options.
- NodeRecord and the run's journal keep nothing for a run of more than one player (Players.Count == 1 guards).
- The engine reads the local player by the local net id (ffi.rs `live`, determinize.rs), not `players[0]`, except the
  fight round cap (world.rs `cap`), which kills `players[0]`.
- NoSL's determinize draws the local player's draw pile again and keeps the teammates' piles as they are: in a
  multiplayer combat it would search on the teammates' real draw order.
- Never run: a multiplayer combat through export → import → observe → PIMC. Unknown whether the import, the
  observation (teammates as allies, intents aimed at several players) and legal actions hold there.

## Decisions

1. **Advice only in multiplayer** (the user). The toolbar's Auto, Play one / Step, Finish turn / Next room buttons are
   not shown in a run of more than one player; `ai auto`, `ai step`, `ai finish` refuse there with a line saying why.
   What the mod reads and the answer it shows are the same code as in a single-player run.
2. **On by default.** A multiplayer run is served like a single-player one; the console switch `ai mp` and
   Assist.Multiplayer are removed, with no setting in their place (the panel's own Assist switch turns it off as
   anywhere).
3. **NoSL only**, as now. The panel's SL/NoSL switch shows NoSL in a multiplayer run and cannot be moved there.
4. **Teammates pass in the search.** The engine runs the imported combat as one player's: our end of turn ends the
   whole side's turn and the teammates play nothing more this turn. The answer is asked again whenever the combat
   changes (a teammate's card changes the state's key), so it follows what they do. The details card's footnote says
   so in a multiplayer run ("teammates taken to play nothing more this turn").
5. **Nothing hidden from the player is read.** Determinize draws every player's hidden piles: the local draw pile from
   its record as now; each teammate's draw pile (and their hand, if the game does not show it to the local player) in a
   new order among its own cards, as nothing of its order is shown to us. Checked against what the game's UI shows of a
   teammate (step 1).
6. **Out-of-combat decisions** (map vote, own rewards, shop, rest, events with their shared votes, treasure vote) are
   answered by V as in a single-player run. V and C never saw a multiplayer run (monster HP scaled by player count,
   shorter maps, 43 multiplayer-only cards read as unknown); no multiplayer data and no net change in this plan.
7. **Card prompts in a fight**: searched as NoSL searches them now (the combat as last written out plus the steps
   since) when every step since that export is the local player's; where a teammate acted in between, "answer the card
   prompt yourself" as now.

## Steps

1. **Read the game for what a teammate shows** (decompiled v0.113.1): whether the local player sees a teammate's hand,
   draw pile count, discard pile; how intents aimed at several players appear; what `ScaleHpForMultiplayer` gives the
   export. Notes in this plan.
2. **A headless multiplayer combat** in the simulator for tests: a run of 2 and 3 players (`SetUpNewSingleplayer` with
   several players, as seed-scout loads a 3-player save), played to its fights with the teammates passing, the local
   seat by our brain. A selftest check: export → import → observe matches the C# observation of the local player;
   legal actions match; PIMC answers with a legal action; determinize keeps what the local player sees of the
   teammates and draws what they cannot. Done when it passes on 20 fights of each player count, every character as
   the local seat.
3. **Engine**: determinize draws the teammates' hidden piles (decision 5); `cap` kills the local player. Engine tests
   on a dump of the multiplayer combats from step 2.
4. **Mod**: decisions 1–3 and 7: Served for every run, the toolbar and console commands that act refused in a
   multiplayer run, the env switch held at NoSL, the prompt rule by the steps' owners. L10n for the new lines in the
   six languages; the details footnote.
5. **Real game**: one co-op run on this machine with two game instances (`--fastmp host` and `--fastmp join
   --clientId 2`, ENet on 127.0.0.1), the user's word first; or a run with a friend. Checked: no divergence kick, the
   panel answers every decision of our seat, nothing acts, answers change after the teammate plays, a vote waits.
6. **Release**: a mod version from the release session; the Workshop texts' "multiplayer coming" line and the upload
   on the user's word.
