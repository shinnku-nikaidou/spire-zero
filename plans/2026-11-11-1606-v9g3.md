## 4. 步驟

1. **檔案與 ledger。** `eval/datasets/v9g3.toml`、ledger 的區段與五列，提交並推送；那個提交（含冠軍檔 v9-3 / c9-3）之後的
   任一已推送提交就是 REV。
2. **smoke。** `box.py launch eval/datasets/v9g3.toml REV --smoke`：每角色一局（+19,000，ε 0.06），step `v9g3-smoke`，1 小時。
   要確認：
   - 每個 shard 的結尾是 `game Log.Error lines: 0; worker restarts: 0; replans: 0`；
   - 紀錄的 `config.commit` 是 REV、`config.env` 是 `SL`、`ascension` 是 10、`config.auto_win` 是 `[0, 1]`；
   - 冠軍字串是 `combat plan c9-3 beam 8x300 easy 4 loss plans 3 … l0 v9-3 clone … explore eps 0.06`；
   - 第 1、2 幕的普通怪戰鬥不掉 HP，精英與 Boss 有打；
   - 有 `explored: true`；
   - 每局耗時（定局數與期限用）。
3. **啟動。** 等用戶說。`box.py launch eval/datasets/v9g3.toml REV`，在 `tmp/compute-timetable.md` 記一列，Colab 照 fleet skill 補上。
4. **排隊。** 啟動時池子上還有 `gate-v9-3`（A10，優先 1，沒有期限）和 `gate-prompts`（優先 0，先啟動）。v9g3 是優先 0，
   會排在兩者之後；要不要插到 `gate-prompts` 前面由用戶決定（`box.py priority`）。
