# The ai console command

The user (2026-11-21): the game's own console (the ~ key) has many commands; design a set beginning with `ai`, then
"他那個命令太少了太簡略，你得研究點牛逼的" and "全部做完吧".

## What the game gives

- `AbstractConsoleCmd` subclasses in a mod's assembly are found and registered by the game itself
  (`ReflectionHelper.GetSubtypesInMods`): no patch.
- `DebugOnly` (true by default) marks the run as debug-used each time; `ai` sets it false (it changes nothing a player
  could not), `scout` (a spoiler) keeps it true.
- One word a command, Tab completion through `GetArgumentCompletions`; output is BBCode in a RichTextLabel, which an
  answer that comes later is added to.

## The commands

One command `ai` with subcommands (`ai help`), and `scout` of its own.

| group | commands | where the answer comes from |
|---|---|---|
| the toolbar, settings | `status` `version` `set` `auto [on|off|until …]` `step` `finish` `restart` | the mod |
| the answer on screen | `why [N]` `legal` `line` `lethal` `danger` | the recommendation and its fight table |
| questions on the side | `try` `deep` `compare` `replay` | `Query`: the decision asked again on a run of its own in the brain |
| V of runs asked about | `deck` `worth` | `ValueQuery` |
| the run's journal | `review` `graph` `quiz` `parity` `mark` | the answers and the steps taken after them (`NodeRecord.Taken`) |
| simulator jobs | `race` `rollout` `scout` `jobs` `stop` | the shipped simulator: `run --progress`, the new `rollout`, the new `scout` |

- Wire v6 adds `Query` / `QueryAnswer` / `CancelQuery` and `ValueQuery` / `ValueAnswer`. A query gets a harness of its
  own from its hello (any environment or effort), its checkpoint and steps, and is dropped once answered: the host's run
  is left as it was. A decision of one legal option is not searched (`PimcBrain.Forced`), so `try` asks with two: the
  option and the answer.
- `rollout`: `RunSession.Load(open: true)` plays past the node, and `RunSession.Redraw` draws every run and player
  stream anew as each later map point is entered, before its room is rolled and its checkpoint taken, so the clones
  the SL brain plays on hold the new streams. What the save has rolled already stays: the act's encounter and event
  order, the relic bag.
- `scout` is the seed-scout probe moved in, on v0.113.1 (`CreateForNewRun` takes `isCustom`); the mod names its ids.
- Jobs run with half the brain's threads, and HOME (APPDATA, USERPROFILE, XDG dirs) of their own in the game
  session's log folder: the headless game they boot never reaches the player's saves.
